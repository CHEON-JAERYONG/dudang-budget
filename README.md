# 🐻💕 찌롱 ♥ 두덩 가계부 2.0

신혼부부 둘이 함께 쓰는 가계부 웹앱. 폰·PC 어디서나 같은 주소로 접속하고, 두 사람의 입력이 실시간으로 동기화돼요.

**주소:** https://cheon-jaeryong.github.io/dudang-budget/

## 특징
- **완전 무료** — 서버·유료 API 없음. 앱은 GitHub Pages, 데이터는 비공개 GitHub 저장소(`dudang-budget-data`)
- **둘이 함께** — 기록 단위 병합이라 동시에 입력해도 덮어쓰지 않음, 오프라인에서도 입력 후 자동 업로드
- **자동 백업** — 모든 변경이 저장소 커밋으로 남음 (누가 언제 무엇을)
- **카드값** — 남편·아내 카드값 따로 입력·집계, 카드 승인 문자 붙여넣기 자동 입력
- **예산** — 남은 예산, 하루 사용 가능 금액, 카테고리 예산
- **고정지출** — 매달 그 날짜에 자동 입력 (두 기기에서 중복 안 됨)
- **실시간 시세** — 국내·해외 주식/ETF(네이버 증권 실시간), 코인(업비트), 원화 환산, 1분마다 갱신
- **자산** — 순자산, 대출 잔액·월 이자, 목표 저축
- **통계** — 카테고리·사람별·결제수단·요일별, 월간/연간, 엑셀(CSV) 내보내기
- PWA(홈 화면 추가), 다크 모드, 잠금 비밀번호

## 구조
```
index.html            앱 셸
css/app.css           디자인 (라이트/다크)
js/store.js           데이터 + GitHub 동기화 (병합/충돌 처리)
js/market.js          시세 (네이버·업비트·환율)
js/views.js           화면 (홈/내역/통계/자산/설정)
js/forms.js           입력 시트
js/app.js             시작·라우팅·자동입력·시세 루프
sw.js                 오프라인 캐시
tools/release.py      버전 올리기: python tools/release.py 2.0.1
```
